# EquityAI Frontend (Fresh Build)

This frontend has been reset and rebuilt from scratch as a clean React + TypeScript + Vite UI starter.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Test

```bash
npm run test
```

Watch mode:

```bash
npm run test:watch
```
